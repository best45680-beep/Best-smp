# BEST-SMP

## About
BEST-SMP is a Minecraft server project focused on
providing an enjoyable and affordable gaming experience.

## Goals
- Learn Linux server administration.
- Learn Minecraft server management.
- Explore VPS hosting technology.
- Eventually provide free game hosting
  for people who cannot afford paid hosting.

## Technology
- Ubuntu Linux
- Minecraft Paper
- Java
- Pterodactyl Panel (planned)

## Status
Currently in development.
